Information about the Web Development:


Web Development is used to make Web sites that include single or multiple web pages having the information or data to be represent. The main elements for building the web sites are HTML, CSS and JavaScript(JS).

HTML


HTML is the skeleton of the web sites. It's add the basic details and info in the web sites.

CSS


CSS add styling in the web site. IT design the web page and decide who the web page will look.

JS


JavaScript is the backbone of a website. IT controls the function at the Backend.
